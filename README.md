Netflix Data Analysis Project

Project Overview

This project analyzes the Netflix Movies and TV Shows dataset using Python, Pandas, and Matplotlib.

Objectives

- Load and explore the Netflix dataset
- Analyze Movies and TV Shows count
- Identify Top 10 Countries with Netflix content
- Create visualizations using graphs

Technologies Used

- Python
- Pandas
- Matplotlib
- VS Code

Dataset Information

Dataset Name: Netflix Movies and TV Shows

Analysis Performed

1. Dataset Shape Analysis
2. First 5 Rows Inspection
3. Movies vs TV Shows Count
4. Movies vs TV Shows Bar Chart
5. Top 10 Countries Analysis
6. Top 10 Countries Visualization

Key Findings

- Netflix contains more Movies than TV Shows.
- Several countries contribute a significant amount of content to Netflix.
